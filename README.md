# 🛡️ DriverSight v2.0 (Blue Team Edition)

**DriverSight** — это автономный программный комплекс для проактивного аудита, инвентаризации и контроля защищенности модулей ядра ОС Windows. 

Инструмент предназначен для специалистов подразделений защиты (Blue Team) и системных администраторов. Он помогает выявлять легитимные, но уязвимые системные драйверы (**BYOVD**-угрозы), а также аномалии нулевого дня (Zero-Day) до того, как они будут использованы злоумышленниками для компрометации ядра (Ring 0) и отключения средств защиты (EDR/AV).

---

## ✨ Ключевые возможности

*   **Низкоуровневая инвентаризация:** Сбор данных о загруженных модулях осуществляется через прямые системные вызовы WinAPI (`psapi.dll`), минуя стандартные и легко обходимые утилиты (вроде `driverquery`).
*   **Гибридный аналитический движок:**
    *   *Сигнатурный контур:* Мгновенная идентификация угроз по SHA-256 хешам на основе актуальной базы знаний LOLDrivers.
    *   *Эвристический контур (Zero-Day):* Парсинг PE-заголовков в памяти на наличие аномальных `RWX`-секций (одновременное чтение, запись и исполнение). Позволяет находить уязвимости, которых еще нет в базах данных.
*   **Активное реагирование (Mitigation):** Интерактивный режим позволяет мгновенно изолировать (отключить автозагрузку) скомпрометированные службы и сгенерировать готовые XML-политики **WDAC** (Windows Defender Application Control) для блокировки угроз на уровне домена.
*   **Режим форензики:** Поддержка сканирования локальных директорий (`--dir`) для анализа образов дисков или проверки файловых хранилищ.
*   **Audit Evidence:** Автоматическая генерация детализированных HTML-отчетов, пригодных для подтверждения ИБ-комплаенса.

## 🚀 Инструкция по развертыванию

### Требования
*   ОС: Windows 10 / 11 (x64).
*   Права: **Локальный администратор** (обязательно для доступа к памяти ядра).
*   Python 3.10+ (при запуске из исходного кода).

### ⚠️ Важный нюанс: База данных
База уязвимых сигнатур (`db.json`) **не включена** в репозиторий GitHub из-за ее частого обновления и размера. Перед началом работы программу необходимо синхронизировать.

### Вариант 1: Запуск из исходного кода (Python)

1. Склонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com/boing737ng/DriverSight.git
   cd DriverSight
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. **Скачайте базу данных сигнатур:**
   ```bash
   python main.py --update
   ```
   *(Скрипт автоматически скачает актуальную базу с LOLDrivers API и создаст папку `data/db.json`)*.
4. Запустите аудит системы:
   ```bash
   python main.py
   ```
### Вариант 2: Сборка в автономный Portable `.exe` (Air-gapped)
Для проверки изолированных сетей без интернета (банковские контуры, АСУ ТП) программу можно скомпилировать в один независимый файл со «вшитой» базой данных.

1. Установите зависимости и обновите базу:
   ```bash
   pip install -r requirements.txt
   pip install pyinstaller
   python main.py --update
   ```
2. Скомпилируйте проект, **обязательно** прикрепив скачанную папку `data`:
   ```cmd
   python -m PyInstaller --onefile --add-data "data/db.json;data" main.py
   ```
3. Готовый `main.exe` появится в папке `dist`. Вы можете переносить его на флешке. Программа будет использовать встроенную базу, но если вы запустите `main.exe --update` на ПК с интернетом, она скачает свежую версию и будет приоритетно использовать её.

## 🛠 Использование и флаги

| Команда | Описание |
| :--- | :--- |
| `python main.py` | Запуск стандартного аудита оперативной памяти (WinAPI). |
| `python main.py --update` | Синхронизация локальной базы с глобальным API LOLDrivers. |
| `python main.py --dir C:\Path\` | Режим форензики: проверка всех `.sys` файлов в указанной папке. |

**Интерактивное реагирование:**
По завершении сканирования, если обнаружены угрозы, система спросит:
1. *Изолировать уязвимые драйверы?* (Служба будет остановлена, а тип запуска в реестре изменен на `disabled`).
2. *Сгенерировать политики WDAC?* (Будет создан файл `WDAC_BlockPolicy_[дата].xml` для распространения через GPO).

## 📊 Оценка рисков

*   **10/10 (Критический):** Драйвер имеет подтвержденную уязвимость *Arbitrary Kernel Write* (произвольная запись в ядро). Позволяет полностью отключить EDR.
*   **8/10 (Высокий):** Драйвер подвержен *Arbitrary Kernel Read*. Угроза утечки системных секретов (например, из LSASS).
*   **7/10 (Zero-Day Risk):** Эвристика обнаружила RWX-аномалию в памяти. Драйвер отсутствует в базах, но архитектурно небезопасен.
